    Simulasi Skenario Concurrency

    Setiap tombol menembakkan beberapa request bersamaan ke API sungguhan memakai token user yang sedang login (), lalu memverifikasi hasilnya.

    AConcurrent Stock Deduction

    Stock Product X di-set 15, lalu 2 user order masing-masing 10 unit bersamaan. Hanya satu boleh berhasil dan stock tidak boleh minus.

    Jumlah pembeli × 10 unit

    BConcurrent Status Update

    Order dibuat dan di-Confirm, lalu request 1 → Shipped dan request 2 → Cancel dikirim bersamaan dengan version yang sama (seperti dua admin di dua tab). Hanya satu menang, yang lain mendapat 409.
